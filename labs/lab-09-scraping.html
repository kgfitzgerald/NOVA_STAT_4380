Introduction

In this lab, you will use rvest functions to scrape data from the internet, and employ data visualization best practices to communicate insights. Several of the web-scraping steps will be done together in class. We will discuss ideas for presentation-ready visualizations in class in Week 12.

Learning goals

By the end of this lab, you should be able to:

  • Use rvest functions to read html tables from the internet
  • Write and read data files
  • Create presentation-ready visualizations
